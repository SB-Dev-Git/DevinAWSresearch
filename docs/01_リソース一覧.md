# リソース一覧

## 概要
本ドキュメントでは、DevinAWSresearchリポジトリのmainブランチに含まれる全リソースとその処理内容を詳細に記載します。

## 1. AWS接続検証システム

### 1.1 メイン実行スクリプト
**ファイル名**: `run_all_verifications.py`
**処理内容**: 
- 3つの検証ステップを順次実行する統合スクリプト
- 各ステップの実行結果を監視し、成功/失敗を判定
- 最終的な検証結果サマリーを生成
- エラーハンドリングとログ出力機能を提供

**主要機能**:
- `run_script()`: 指定されたPythonスクリプトを実行し、結果を返す
- `main()`: 3つの検証ステップを順番に実行し、総合結果を表示

### 1.2 ステップ1: 基本認証確認
**ファイル名**: `step1_basic_auth.py`
**処理内容**:
- AWS認証情報の確認とユーザー情報の取得
- STS（Security Token Service）を使用した認証状態の検証
- ユーザーID、アカウントID、ARNの取得と表示

**主要機能**:
- `verify_basic_auth()`: AWS認証情報の基本確認を実行
- NoCredentialsError、ClientErrorの適切なハンドリング

### 1.3 ステップ2: サービス接続テスト
**ファイル名**: `step2_service_connection.py`
**処理内容**:
- S3、EC2、その他のAWSサービスへの接続確認
- 各サービスの基本的な操作テスト
- 利用可能リージョンの確認

**主要機能**:
- `test_s3_connection()`: S3バケット一覧取得とアクセステスト
- `test_ec2_connection()`: EC2インスタンス情報取得とステータス確認
- `test_regions()`: 利用可能リージョンの確認
- `verify_service_connections()`: 全サービス接続テストの統合実行

### 1.4 ステップ3: 包括的検証システム
**ファイル名**: `step3_comprehensive_verification.py`
**処理内容**:
- 複数リージョン、IAM権限、エラーハンドリングを含む包括的なAWS接続検証
- 並列処理による効率的なリージョンテスト
- 詳細なレポート生成機能

**主要機能**:
- `AWSComprehensiveVerifier`: 包括的検証を行うメインクラス
- `test_iam_permissions()`: IAM権限の詳細確認
- `test_multi_region_connectivity()`: 複数リージョンでの並列接続テスト
- `test_service_limits()`: サービス制限の確認
- `test_error_handling()`: エラーハンドリングテスト
- `generate_report()`: JSON形式での詳細レポート生成
