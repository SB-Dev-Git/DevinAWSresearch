## 3. デプロイ自動化システム

### 3.1 デプロイスクリプト構成

#### 3.1.1 start_instances.sh
```bash
#!/bin/bash
# EC2インスタンス起動スクリプト

echo "🚀 EC2インスタンス起動を開始します..."

# 制御ノード起動
echo "制御ノード起動中..."
aws ec2 start-instances --instance-ids i-control-node-id

# ターゲットノード起動
echo "ターゲットノード起動中..."
aws ec2 start-instances --instance-ids i-target-node-id

# 起動完了待機
echo "インスタンス起動完了を待機中..."
aws ec2 wait instance-running --instance-ids i-control-node-id i-target-node-id

echo "✅ 全インスタンスの起動が完了しました"
```

**実行方法**:
```bash
chmod +x start_instances.sh
./start_instances.sh
```

#### 3.1.2 deploy_hello_world.sh
```bash
#!/bin/bash
# Hello World アプリケーションデプロイスクリプト

echo "🎯 Hello World アプリケーションデプロイを開始します..."

# templatesディレクトリ確認・作成
if [ ! -d "templates" ]; then
    echo "📁 templatesディレクトリを作成します..."
    mkdir templates
fi

# テンプレートファイル転送
echo "📄 テンプレートファイルを準備します..."
cp package.json templates/package.json.j2
cp app.js templates/app.js.j2

# Ansibleプレイブック実行
echo "🔧 Ansibleプレイブックを実行します..."
ansible-playbook -i ansible_inventory.ini web_server_setup.yml -v

# デプロイ結果確認
if [ $? -eq 0 ]; then
    echo "✅ デプロイが正常に完了しました！"
    echo "🌐 アプリケーションアクセス: http://13.230.71.11"
else
    echo "❌ デプロイ中にエラーが発生しました"
    exit 1
fi
```

**実行方法**:
```bash
chmod +x deploy_hello_world.sh
./deploy_hello_world.sh
```

## 6. バックアップ・復旧

### 6.1 バックアップ戦略

#### 6.1.1 アプリケーションバックアップ
```bash
#!/bin/bash
# backup_app.sh

BACKUP_DIR="/backup/$(date +%Y%m%d_%H%M%S)"
mkdir -p $BACKUP_DIR

# アプリケーションファイル
cp -r /opt/hello-world-webapp $BACKUP_DIR/

# Nginx設定
cp -r /etc/nginx/conf.d $BACKUP_DIR/

# systemdサービス
cp /etc/systemd/system/hello-world-webapp.service $BACKUP_DIR/

echo "バックアップ完了: $BACKUP_DIR"
```

#### 6.1.2 設定ファイルバックアップ
```bash
# Ansible設定バックアップ
tar -czf ansible_config_$(date +%Y%m%d).tar.gz \
    ansible_inventory.ini \
    web_server_setup.yml \
    target_server_verification.yml \
    templates/
```

### 6.2 復旧手順

#### 6.2.1 アプリケーション復旧
```bash
# サービス停止
systemctl stop hello-world-webapp nginx

# バックアップから復元
cp -r $BACKUP_DIR/hello-world-webapp /opt/
cp -r $BACKUP_DIR/conf.d/* /etc/nginx/conf.d/
cp $BACKUP_DIR/hello-world-webapp.service /etc/systemd/system/

# 権限修正
chown -R nodejs:nodejs /opt/hello-world-webapp
chmod +x /opt/hello-world-webapp/app.js

# サービス再起動
systemctl daemon-reload
systemctl start hello-world-webapp nginx
```

#### 6.2.2 完全再構築
```bash
# 既存環境クリーンアップ
systemctl stop hello-world-webapp nginx
rm -rf /opt/hello-world-webapp
userdel nodejs

# Ansibleで再デプロイ
./deploy_hello_world.sh
```

const numCPUs = require('os').cpus().length;

if (cluster.isMaster) {
    // マスタープロセス
    for (let i = 0; i < numCPUs; i++) {

#### 8.1.2 Nginx最適化
```nginx
# /etc/nginx/conf.d/hello-world-webapp.conf 最適化
upstream nodejs_backend {
    server 127.0.0.1:3000;
    keepalive 32;
}

server {
    listen 80;
    
    # gzip圧縮
    gzip on;
    gzip_types text/plain text/css application/json application/javascript;
    
    # キャッシュ設定
    location ~* \.(css|js|png|jpg|jpeg|gif|ico)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
    
    location / {
        proxy_pass http://nodejs_backend;
        proxy_http_version 1.1;
        proxy_set_header Connection "";
    }
}
```

### 8.2 監視・アラート

#!/bin/bash
# monitor.sh

# CPU使用率チェック

if (( $(echo "$CPU_USAGE > 80" | bc -l) )); then
    echo "警告: CPU使用率が高いです ($CPU_USAGE%)"

# メモリ使用率チェック

## 9. トラブルシューティング

### 9.1 よくある問題と解決方法

#### 9.1.1 Ansible接続エラー
**問題**: `UNREACHABLE! => {"changed": false, "msg": "Failed to connect to the host via ssh"}`

**解決手順**:
```bash
# 1. SSH接続テスト
ssh -i /home/ec2-user/oshima_devin.pem ec2-user@13.230.71.11

# 2. 鍵権限確認
ls -la /home/ec2-user/oshima_devin.pem

# 3. セキュリティグループ確認
aws ec2 describe-security-groups --group-ids sg-xxxxxxxxx

# 4. インスタンス状態確認
aws ec2 describe-instances --instance-ids i-xxxxxxxxx
```

#### 9.1.2 Node.jsアプリケーション起動エラー
**問題**: `Job for hello-world-webapp.service failed`

**解決手順**:
```bash
# 1. サービスログ確認
journalctl -u hello-world-webapp -n 50

# 2. アプリケーションファイル確認
ls -la /opt/hello-world-webapp/
cat /opt/hello-world-webapp/app.js

# 3. 手動実行テスト
sudo -u nodejs /usr/bin/node /opt/hello-world-webapp/app.js

# 4. ポート使用状況確認
netstat -tlnp | grep :3000
```

#### 9.1.3 Nginx設定エラー
**問題**: `nginx: [emerg] bind() to 0.0.0.0:80 failed`

**解決手順**:
```bash
# 1. ポート使用状況確認
netstat -tlnp | grep :80

# 2. Nginx設定テスト
nginx -t

# 3. 設定ファイル確認
cat /etc/nginx/conf.d/hello-world-webapp.conf

# 4. 他のWebサーバ停止
systemctl stop httpd apache2
```

### 9.2 緊急時対応

#### 9.2.1 サービス復旧手順
```bash
# 1. 全サービス停止
systemctl stop hello-world-webapp nginx

# 2. プロセス強制終了（必要に応じて）
pkill -f "node.*app.js"
pkill nginx

# 3. 設定確認・修正
nginx -t
journalctl -u hello-world-webapp --since "1 hour ago"

# 4. サービス再起動
systemctl start hello-world-webapp
systemctl start nginx

# 5. 動作確認
curl -I http://localhost
curl http://localhost
```

#### 9.2.2 ロールバック手順
```bash
# 1. 前回のバックアップ確認
ls -la /backup/

# 2. 現在の設定バックアップ
cp -r /opt/hello-world-webapp /tmp/current_backup_$(date +%Y%m%d_%H%M%S)

# 3. 前回の設定復元
cp -r /backup/YYYYMMDD_HHMMSS/hello-world-webapp /opt/

# 4. サービス再起動
systemctl restart hello-world-webapp nginx
```
