# 処理設計書

## 概要
本ドキュメントでは、DevinAWSresearchシステムの各処理フローと設計仕様を詳細に説明します。

## 1. AWS接続検証システム処理設計

### 1.1 統合実行処理（run_all_verifications.py）

#### 処理フロー
```
開始
  │
  ├─ 実行時刻記録
  │
  ├─ 検証ステップ定義
  │   ├─ step1_basic_auth.py
  │   ├─ step2_service_connection.py
  │   └─ step3_comprehensive_verification.py
  │
  ├─ 各ステップ順次実行
  │   │
  │   ├─ ファイル存在確認
  │   │   ├─ 存在する → スクリプト実行
  │   │   └─ 存在しない → エラー記録
  │   │
  │   ├─ subprocess.run()でPython実行
  │   │   ├─ 成功（return code = 0）
  │   │   │   ├─ 成功メッセージ表示
  │   │   │   └─ 2秒待機
  │   │   └─ 失敗（return code ≠ 0）
  │   │       ├─ 失敗メッセージ表示
  │   │       └─ 次ステップ継続
  │   │
  │   └─ 結果配列に記録
  │
  ├─ 最終結果サマリー生成
  │   ├─ 成功ステップ数計算
  │   ├─ 各ステップ結果表示
  │   └─ 総合結果判定
  │
  └─ 終了（成功時: exit 0, 失敗時: exit 1）
```

#### 主要関数設計

**run_script(script_name, step_description)**
- **入力**: スクリプト名、ステップ説明
- **処理**: 
  1. 実行開始メッセージ表示
  2. subprocess.runでPython実行
  3. 戻り値チェック
  4. 結果メッセージ表示
- **出力**: 成功/失敗のブール値
- **例外処理**: Exception捕捉とエラーメッセージ表示

**main()**
- **入力**: なし
- **処理**:
  1. 開始メッセージと時刻表示
  2. 検証ステップ配列定義
  3. 各ステップのrun_script()呼び出し
  4. 結果集計と表示
- **出力**: 総合成功/失敗のブール値

## 4. エラーハンドリング設計

### 4.1 AWS検証システムエラーハンドリング

#### 共通エラー処理パターン
```python
try:
    # AWS API呼び出し
    result = aws_client.api_call()
    # 成功処理
    return True
    
except NoCredentialsError:
    # 認証情報未設定エラー
    print("❌ AWS認証情報が設定されていません")
    return False
    
except ClientError as e:
    # AWS APIエラー
    error_code = e.response['Error']['Code']
    print(f"❌ AWS APIエラー: {error_code}")
    return False
    
except Exception as e:
    # 予期しないエラー
    print(f"❌ 予期しないエラー: {e}")
    return False
```

#### 特定エラー処理

**IAM権限エラー**
```python
except ClientError as e:
    if e.response['Error']['Code'] == 'AccessDenied':
        details['iam_access'] = 'アクセス拒否（IAM読み取り権限なし）'
    else:
        raise
```

**S3バケットエラー**
```python
except ClientError as e:
    if e.response['Error']['Code'] in ['404', 'NoSuchBucket']:
        # 正常なエラー（テスト用）
        success = True
    else:
        # 予期しないエラー
        success = False
```

## 5. パフォーマンス設計

### 5.1 並列処理設計

#### 複数リージョンテスト並列化
```python
with ThreadPoolExecutor(max_workers=5) as executor:
    future_to_region = {
        executor.submit(test_region_connectivity, region): region 
        for region in test_regions
    }
    
    for future in as_completed(future_to_region):
        result = future.result()
        results.append(result)
```

**設計考慮事項**:
- **max_workers=5**: リージョン数に合わせた最適化
- **as_completed()**: 完了順での結果取得
- **タイムアウト処理**: 長時間応答なしの場合の処理
